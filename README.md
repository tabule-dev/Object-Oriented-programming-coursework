# Object-Oriented-programming-coursework

This repository contains two Java projects developed as part of my  programming coursework. Both projects are written in java and are ready to run in NetBeans  
---
Project 1: Physics Quiz Grading Program

A Java program that automates grading for a quiz based on Uganda's O-Level grading system. The program allows the teacher to input student scores and automatically determines the corresponding grade and remark.
Features
- Prompts the user to enter a student's score (0–100).  
- Determines the grade and remark using if-else-if statements.  
- Displays the score, grade and remark.  
- Extended functionality: processesscores for 5 students and displays a summary showing how many students scored each grade.
 How to Run
1. Open the `QuizGrading` project in NetBeans.  
2. Run the `QuizGrading.java` file.  
3. Enter the student scores as prompted.  
4. View grades and remarks in the console.

Project 2: SK Motors Auction Program
 Description
A Java program that simulates a vehicle auction system for SK Motors. The system accepts bids from multiple bidders, selects the highest bidder, and calculates profit or loss for the vehicle based on deposits and expenses.
Features
- Accepts vehicle detail: registration number, cost, and balance left.  
- Accepts bids from 3 bidders and determines the highest bidder.  
- Captures deposits and expensesrelated to the vehicle.  
- Calculates and displays profit or loss  
- Displaysvehicle details,winner**, and profit/loss in the console.
How to Run
1. Open the `SKMotorsAuction` project in NetBeans.  
2. Run the `SKMotorsAuction.java` file.  
3. Enter vehicle details, bidder bids, deposits, and expenses as prompted.  
4. View the highest bidder and profit/loss in the console.
